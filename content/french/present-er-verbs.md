# Le présent: regular -er verbs

Drop **-er** from the infinitive, add the ending that matches the subject.

| Subject | Ending | [[parler]] |
|---|---|---|
| je | -e | parle |
| tu | -es | parles |
| il / elle | -e | parle |
| nous | -ons | parlons |
| vous | -ez | parlez |
| ils / elles | -ent | parlent |

> <mark>je</mark> becomes **j'** before a vowel: *j'[[aime|aimer]]*, *j'[[habite|habiter]]*.

## Practice sentences
- Je parle français.
- Nous [[habitons|habiter]] à Paris.
- Ils [[aiment|aimer]] le chocolat.
