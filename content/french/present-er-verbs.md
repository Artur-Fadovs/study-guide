# Le présent: regular -er verbs

Drop **-er**, add the ending that matches the subject.

| Subject | Ending | parler |
|---|---|---|
| je | -e | parle |
| tu | -es | parles |
| il / elle | -e | parle |
| nous | -ons | parlons |
| vous | -ez | parlez |
| ils / elles | -ent | parlent |

> <mark>je</mark> becomes **j'** before a vowel: *j'aime*, *j'habite*.
